0 · Library backfill (r24): empty SPEC_NAME/MATERIAL + uniform Family & Type library record → values filled, element tagged LIB. Filled params are never overwritten; ambiguous families never backfill. 1 · Material: SPEC_MATERIAL_TEXT_EN → segment XX.XX. (exact, then substring). 2 · Fitting: SPEC_NAME_EN → XX.XX.YY. (144 rules); Family & Type fallback + cross-check (61) — name wins, disagreement flags. 3 · Size: SPEC_SIZE / RBS_CALCULATED_SIZE → NW parse → atomic leaf; sized types refuse fallback (loud size-miss). 4 · Bill (r24): unit + contract per atomic from the source BOQ → totals in the code's own unit, Δ against contract.
