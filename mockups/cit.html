Marker size

A clash report carries no geometry size. Leave this off for a fixed-geometry coordination marker; turn it on to write a size into every instance, taken from the report where it carries one and from these figures everywhere else.
Write size parameters
Width mm Height mm Diameter mm
'Diameter' is a TYPE parameter on this family, so a size cannot be written per marker — one write would resize every instance of the type. Those writes will be declined. Make it an instance parameter in the family editor, or leave size writing off.

Settings

Saved to cit_config.json beside this tool. The size-parameter lists are tried in order and the first name that exists, is writable and takes a length wins.

Marker identity

Mark prefix State parameter
The state is written as a short [CIT|…] token inside that parameter, alongside anything already written there — your own text is preserved. Changing the parameter after markers exist orphans the ones already stamped.
Markers are stamped prefix + a sequential number, continuing from the highest number already in the model. Keep this different from the MEP Opening Tool's WOT- prefix: both write the same Mark parameter, and a shared prefix makes the two sequences renumber each other.

Size parameter names

Width
Height
Diameter
Comma separated. A name of Radius receives half the diameter. These are shared with the MEP Opening Tool, so a change here changes both.

Size from the report

Navisworks reports no sizes of its own, but a model appended with its parameters carries them as object attributes. Any of these keys, found on either side of a clash, is read as that clash's size.
